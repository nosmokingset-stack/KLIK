# KLIK V1.3 · 26 ноября 2026

## Ошибка формы заказа

С публичного адреса https://klickkhua.blogspot.com/ получен HTML установленной V1.2. В нём присутствовали обе кнопки с атрибутами `data-order-quantity`, элемент `dialog` и скрипт приложения. Blogger вернул начало скрипта буквально как `<script type='text/javascript'><![CDATA[`. В документе типа text/html браузер передаёт этот фрагмент интерпретатору JavaScript. Chrome выдал `Unexpected token '<'` до выполнения первой инструкции приложения.

В контрольном опыте открыли сохранённый HTML в Chrome. Первая карточка воспроизвела сбой. Затем в этом же HTML закомментировали маркеры CDATA для JavaScript. Обе карточки стали открывать форму. В сборщике V1.3 реализованы границы `//<![CDATA[` и `//]]>`. XML-парсер продолжает читать скрипт как CDATA, а JavaScript допускает обе формы сериализации Blogger. Прежние обработчики всей карточки, выбор комплекта и управление фокусом сохранены.

## Проверка версии

- Chromium (настольный Chrome), ширины 320, 375, 390, 768, 1024, 1440 и 1920 px. На каждой ширине проверены UA/RU, переход меню к инструкции, открытие каждой карточки по изображению, предвыбор комплекта, сумма 199/299 грн, видимость второго переключателя, возврат фокуса после Escape, габариты страницы и диалога.
- Обе одиночные расцветки и четыре сочетания для пары. Для синего показывается статус изготовления. Поля сохраняют значения после смены комплекта и языка.
- Маска преобразовала тестовый номер в формат +380 (XX) XXX-XX-XX. Пустая форма показала четыре ошибки. Валидная форма сообщила о недоступности отправки. Запросов POST за время отправки тестовой формы было 0.
- Проверены кнопка закрытия, клик по фону, клавиша Escape, FAQ, наличие шести секций и восьми вопросов. На локальной версии не зарегистрировано исключений JavaScript.
- Валидность XML проверена парсером lxml. Все ID уникальны, локальные якоря имеют цели. Проверены размеры и alt изображений, URL src и srcset. Canonical XML берётся из Blogger.
- Все 43 URL в asset-links.json проверены анонимным HTTPS GET. Для растровых изображений полученные байты совпали с локальными файлами. В SVG при сравнении учтены окончания строк Windows. Результаты, размер и SHA-256 содержатся в preview/public-links-v1.3.json.
- XML занимает около 87 КиБ. Четыре новых WebP для страницы вместе занимают около 241 КиБ. PNG-мастер хранится отдельно. Ниже первого экрана используются ленивые изображения. Тесты выполнялись с системными запасными шрифтами; сетевой LCP на устройстве покупателя не измерялся.
- Полные снимки при ширинах 1440 и 390 px, отдельные виды пяти секций и двух комплектов находятся в preview с суффиксом v1.3. Визуально проверены фото, последовательность кадров, раскладка и компоновка формы.

## Проверка после установки

1. Сохранить резервную копию установленной темы в Blogger. Открыть предварительный просмотр новой темы.
2. Нажать «Замовити», затем на изображение первой карточки. Проверить сумму 199 грн. Закрыть окно и открыть вторую карточку. Проверить сумму 299 грн и два отдельных переключателя цветов.
3. Выбрать разные цвета, переключить язык, проверить статус синей кнопки, заполнение формы и закрытие. Повторить на телефоне и по адресу с параметром ?m=1.
4. Проверить Console и Network после сохранения темы. Вкладка Console должна показывать исполняемый скрипт без синтаксической ошибки, а WebP должны загружаться по HTTPS.

Установка V1.3 в Blogger ожидает отдельного согласия владельца. Проверка опубликованной V1.3 остаётся этапом после установки.
