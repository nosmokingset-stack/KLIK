# Publication scope — KLIK v1.1

Public repository: https://github.com/nosmokingset-stack/KLIK

Included: the user-approved current KLIK logo, prepared product WebP images (including the explicitly identified blue visualization), the newly approved demonstration comparison crops, code-native waves/drops/icons, website source and release preview screenshots.

The source comparison and source product PNG/photo files are retained locally. The comparison is a digital demonstration and is not evidence of a real compatibility test. Its visible disclaimer is localized.

Excluded: all supplied water-station photographs because their publication rights are unconfirmed, all rejected generative station edits, local review pages, source screenshots, archives, environment-specific scripts, private attachments and credentials. A public status note is provided in assets/water-stations/PUBLIC-STATUS.md.

The public Git allowlist is in .gitignore; public-files.txt lists the intended tracked files. Public commit authors use the GitHub noreply address. Other repositories are untouched.

Asset URLs are centralized in assets.config.json, generated into template.xml, and inventoried in asset-links.json. The final release pins the asset base to an immutable commit SHA. Keep previously used image paths available for earlier templates.

The Blogger theme itself has not been installed or published. This GitHub publication was explicitly requested for source control and asset hosting.
