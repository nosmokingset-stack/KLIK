# KLIK Orders: підготовка приватної таблиці

Це перша частина V1.5, не публічний сервіс замовлень. У цих модулях немає публічної точки входу, надсилання листів або створення накладних. Тема Blogger залишається V1.4.

- Проєкт Apps Script має бути прив’язаний до **нової приватної** таблиці «KLIK – Замовлення». Не використовуйте скрипт або таблицю іншого магазину.
- У налаштуваннях проєкту, у розділі Script Properties, власник додає `NOVA_POSHTA_API_KEY`. Не записуйте ключ у таблицю, код або журнал.
- Після перезавантаження таблиці меню **KLIK → Підготувати таблицю** запускає ініціалізацію. Перше виконання може запитати дозволи Google. З'являться п'ять аркушів: замовлення, налаштування, статистика, відділення й журнал. Прийом замовлень та синій колір початково вимкнені.
- **KLIK → Оновити відділення Харкова** завантажує довідник, перевіряє область і місто, відбирає відділення та записує результат у журнал. Використовуються лише методи читання. Розклад автоматичного оновлення ще не налаштований.
- Статистика трактує отримані замовлення за їхнім статусом, не як підтвердження банківського платежу. Часткові повернення не відображаються окремо.

Перед підключенням форми потрібні перевірка реальної відповіді API, завершення серверної обробки замовлень і окремий тестовий запуск. Ідентифікатори приватних ресурсів та облікові дані не входять до цих вихідних файлів.
