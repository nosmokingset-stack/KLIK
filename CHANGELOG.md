# История изменений

## Оптимизация Новой почты — 2026-11-27

- Изучены клиент и реальный Apps Script сервера заказов NOSMOKINGSET исключительно для чтения. Подтверждён точечный поиск FindByString вместо полной выгрузки города.
- В KLIK заменены datalist на связанные с полем прокручиваемые combobox/listbox; добавлены клавиатура, закрытие, выбранная строка и защита от запоздалых ответов.
- Добавлены нормализованный кэш публичного справочника на 3 минуты, дедупликация запросов, вывод первой страницы без ожидания остальных и локальный поиск по номеру/адресу.
- Подготовлен и сохранён в Apps Script KLIK метод pointsSearch с поиском через FindByString. Рабочее развёртывание не обновлялось; для включения метода требуется redeploy KLIK.
- Сохранены цены, серверная перепроверка конфигурации перед заказом, Ref-валидация, POST-транспорт и сохранение заказов. Языковое переключение больше не повторяет запрос конфигурации.
- Выполнены реальные замеры Chrome до/после на 1440/390 px, тесты гонок/интерфейса на 1440/768/390/320 px, проверки серверного справочника и регрессий заказов.

## 1.5 · 2026-11-26

- Декоративные переходы переработаны в шесть индивидуальных волнообразных лент-флагов с единой синей и жёлтой полосой и мягким светом складок.
- Заменены нижние волновые переходы на шесть разных жёлто-синих SVG-лент по верхним границам секций; обновлён один пункт сравнения на украинском и русском.
- Управление приёмом заказов оставлено только за переключателем в Google Sheets. Состояние проверяется сервером повторно перед записью; клиент обновляет его при оформлении.
- Добавлен независимый выбор цветов для каждой кнопки, отправка цвета каждой кнопки отдельной строкой в уведомлении, управление доступностью обоих цветов через настройки. Текст оплаты в форме сокращён.
- Подготовлен отдельный Apps Script KLIK: прямой поиск населённых пунктов, отделений и почтоматов Новой почты с кратковременным кэшем и ограничением частоты.
- В форме добавлены выбор населённого пункта и точки, проверка согласия, серверная проверка цены и наличия, сохранение, нумерация, защита от повтора и уведомления на адрес из настроек.
- Актуализированы тексты доставки по Украине в UA/RU и предварительных документах. Публичный контактный email не менялся.
- Реальные заказы выключены переключателем в настройках; его состояние проверяется на сервере. Тестирование выполнено на вымышленных данных в отдельной таблице; тестовый Web App отключён.
